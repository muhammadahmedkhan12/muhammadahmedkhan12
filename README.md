## 🚀 Projects

### 🌾 [FasalAI](https://github.com/muhammadahmedkhan12/Fasal-AI) — AI-Powered Agricultural Export Compliance
> Built for the **National AI Hackathon powered by Atomcamp**

A multi-agent AI system that helps Pakistani farmers and exporters navigate SPS, MRL, and phytosanitary compliance for international markets (EU, USDA, Gulf).

- **5 specialist AI agents** (CrewAI): MRL Checker, SPS Standards, Document Generator, Risk Flagger, and Urdu Language Agent
- **RAG pipeline** (ChromaDB + LangChain) over EU Regulation EC 396/2005, IPPC standards, and Gulf GCC food safety docs — sub-2-second compliance lookups
- **Live API integrations**: EU Pesticides DB, RASFF border alert API, USDA FAS MRL database — cross-checking 50+ export markets in real time
- **Urdu language agent** making regulatory output accessible to smallholder farmers
- Auto-generates pre-filled export documents, cutting preparation time from days to minutes
